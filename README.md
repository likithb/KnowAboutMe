# KnowAboutMe Portfolio Site

A self-contained portfolio website for Likith Battigiri.

## Run locally

Open `index.html` in a browser, or serve the folder with any static server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy

This branch is ready for GitHub Pages or any static hosting service. No build step is required.
